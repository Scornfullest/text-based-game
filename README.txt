If this is your first time playing I recommend reading this document. (If you don't want to read allat you're not gonna like the type of game this is. ;-p Although you might just really be itching to get into the game.)

This is a Text-Based Interactive Fiction game, it's a bit like the Text Adventure games of the last century (although they still exist, of course). If you've played those before you probably know how they work, HOWEVER, this game is slightly different.

CONTROLS

This game works with a two-word input in the form of "<verb>  <adjective>". (Because I'm not making a parser, I'm not that skilled or patient.)

For example:

go north

use torches

This would result in the game responding to you in some way.

There is multiple variations of each input, so just try some verbs and adjectives  until something works.


DESC

You don't need to read this to start playing.

An Interactive Fiction game where you play as a knight who has lost his memory. Make your way trough various challenges while learning more about the world.
